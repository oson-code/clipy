Everything you copied, one shortcut away.

Clipy keeps your clipboard history and snippets in a menu that opens right at the mouse pointer. Pick an item and it is pasted into the app you were using. A Linux port of Clipy for macOS.

Built for the way you already work

The menus, settings and snippet editor match Clipy for macOS, adapted to Linux shortcuts and desktops.

Menu at the pointer

Press Super Shift V and the history opens where you are looking, not in a corner of the screen.

Pastes for you

Choose an item and Clipy types the paste key in the app you were using. Terminals get Ctrl Shift V.

Snippets in folders

Keep replies, addresses and code in folders, each with its own shortcut. Imports and exports Clipy's XML.

Images and colours

Copied images show as thumbnails and colour codes as swatches. Optionally saves new screenshots to the history.

Private by default

History stays on your computer in a database only you can read. Passwords copied from KeePassXC can be skipped.

Keyboard friendly

Number keys pick the first ten items. Hold Ctrl while choosing to paste plain text or remove an item.

Works on your desktop

Clipy captures every copy on any desktop. How much else works depends on the session.

Everything

X11: Linux Mint Cinnamon, Ubuntu on Xorg, XFCE, MATE, KDE X11

Global shortcuts, the menu at the pointer, automatic paste and clipboard capture.

Everything

GNOME on Wayland 45–50: Ubuntu 24.04, 25.x, 26.04

With the Clipy GNOME Shell extension, which the package installs. Log out and back in once after installing.

Partial

KDE Plasma and wlroots on Wayland

History and the panel menu work. Global shortcuts wait for the GlobalShortcuts portal; paste needs ydotool or wtype.

Ubuntu 22.04 runs GNOME 42, which the extension does not support: choose “Ubuntu on Xorg” at the login screen there.

Shortcuts

All of them can be changed in Preferences → Shortcuts.

Install

Add the Clipy repository once, and new versions arrive with your regular system updates.

From the APT repository Recommended

Ubuntu, Linux Mint, Debian and Pop!_OS.

$ sudo wget -qO /etc/apt/sources.list.d/clipy.sources \
    https://oson-code.github.io/clipy/clipy.sources
$ sudo apt update
$ sudo apt install clipy
$ clipy &   # first start asks whether to launch on login

On GNOME Wayland, log out and back in once so GNOME loads the Clipy extension, then run gnome-extensions enable clipy@osoncode.uz if it is not on yet.
